## 2. Implemented Project Extensions

The current project expands the study into an individual comparative analysis across multiple deep learning architectural families. Implemented extensions include:

1. **MLP Baseline Integration**: Implementation of a non-spatial multi-layer perceptron baseline (`MLPBaseline`) accepting flattened pixel inputs (150,528 features).
2. **Custom CNN Baseline Integration**: Implementation of a 4-stage convolutional neural network (`CNNBaseline`) trained from scratch with batch normalization and global average pooling.
3. **Vision Transformer (ViT-B/16) Integration**: Integration of `torchvision.models.vit_b_16` with a custom dropout-linear classification head, supporting frozen backbone and full fine-tuning stages.
4. **Configuration-Aware Experiment Architecture**: Modular YAML-based experiment runners with dedicated output directories.
5. **GPU Execution Validation**: Preflight verification and hardware safety checks for CUDA acceleration.
6. **Unified Cross-Model Comparison Framework**: Automated schema normalization, metric verification, publication-ready table generation (Markdown, LaTeX, CSV), and multi-metric comparative visualizations (`src/compare.py`).
7. **Reproducibility & Fairness Auditing**: Split hash verification, confusion matrix dimension integrity checks, and evaluation protocol alignment across all models.

## 3. Pretrained Weights Disclosure

Pretrained model backbones utilized in transfer learning experiments were obtained from the official PyTorch torchvision model repository:

* **ResNet-18**: `torchvision.models.ResNet18_Weights.DEFAULT` (Pretrained on ImageNet-1K)
* **ViT-B/16**: `torchvision.models.ViT_B_16_Weights.DEFAULT` (Pretrained on ImageNet-1K)
* **EfficientNet-B0**: `torchvision.models.EfficientNet_B0_Weights.DEFAULT` (Pretrained on ImageNet-1K)
